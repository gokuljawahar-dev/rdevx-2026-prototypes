# RDevX 2026 Purpose-Built Prototypes

One static GitHub Pages repository containing three deliberately distinct products:

- **Gateway** — a calm, guided Level 1 candidate-screening journey.
- **Horizon** — a dense, exception-first engagement-governance cockpit.
- **Sentinel** — a live, worst-first delivery-risk operations center.

Each product owns its own `assets/styles.css` and `assets/app.js`, instruments, journeys, governance levers, IDS navigation, screen-space controls and local state. No framework, build step, CDN, web font or network call is used.

## Publish

Enable GitHub Pages once for the `main` branch and repository root. The root landing page links to `gateway/`, `horizon/` and `sentinel/`.
